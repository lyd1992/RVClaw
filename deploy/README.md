# K3 deployment

Target path:

```text
/data/RVClaw
```

## 1. Copy or clone

```bash
mkdir -p /data/RVClaw
cd /data/RVClaw
git clone https://github.com/lyd1992/RVClaw.git .
```

If GitHub is unavailable on K3, upload the repository contents from the
development machine to `/data/RVClaw`.

## 2. YOLOv8n model

Studio target boxes are generated by YOLOv8n. Before starting the Studio, make
sure the Python package and model file are ready.

Install the runtime package:

```bash
python3 -m pip install ultralytics opencv-python
```

Default model path on K3:

```text
/data/RVClaw/models/yolov8n.pt
```

If the device can access the internet, the first run can download `yolov8n.pt`
automatically through `ultralytics`.

If the device cannot access the internet, download `yolov8n.pt` on another
machine and copy it to:

```text
/data/RVClaw/models/yolov8n.pt
```

If you want to use another model path, set:

```bash
export RVCLAW_YOLO_MODEL=/data/RVClaw/models/yolov8n.pt
export RVCLAW_YOLO_CONF=0.35
```

After starting the service, check whether the model is ready:

```bash
curl http://127.0.0.1:8017/api/vision-state
```

If the response contains `"available": true`, the model is ready and Studio can
show real detection boxes. If it contains `"available": false`, the page can
still open, but the model package or `yolov8n.pt` file is not ready yet.

## 3. Start Studio/API

```bash
cd /data/RVClaw
python3 scripts/serve_studio.py --host 0.0.0.0 --port 8017
```

Open:

```text
http://K3_IP:8017/
```

Verify F5/F7:

```bash
curl http://127.0.0.1:8017/api/vision-state
curl http://127.0.0.1:8017/api/person-tracking
```

## 4. systemd service

```ini
[Unit]
Description=RVClaw EdgeOne Studio
After=network.target

[Service]
Type=simple
WorkingDirectory=/data/RVClaw
Environment=RVCLAW_YOLO_MODEL=/data/RVClaw/models/yolov8n.pt
Environment=RVCLAW_YOLO_CONF=0.35
ExecStart=/usr/bin/python3 /data/RVClaw/scripts/serve_studio.py --host 0.0.0.0 --port 8017
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

Install:

```bash
cat >/etc/systemd/system/rvclaw-studio.service
systemctl daemon-reload
systemctl enable rvclaw-studio
systemctl start rvclaw-studio
journalctl -u rvclaw-studio -f
```
